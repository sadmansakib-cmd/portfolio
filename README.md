# Sadman — Personal Portfolio

A clean, modern, and professional portfolio for **Sadman**, a Computer Science & Engineering student building real-world solutions through code.

> _"Building real-world solutions through code."_

## ✨ Features

- 🌗 **Dark & Light mode** (with system preference + persistence)
- 🎯 **Growth-focused brand** — execution, consistency, real-world impact
- 📱 **Fully responsive** — mobile-first design
- ⚡ **Next.js 14 + TypeScript + Tailwind CSS**
- 🧩 **Single content file** — edit `lib/data.ts` to update everything

## 📂 Sections

1. **Hero** — Tagline, intro, current focus
2. **About Me** — Bio + 3 guiding principles + key stats
3. **Skills** — Programming, IoT, Problem Solving, Mindset
4. **Featured Projects** — Each shown with **Problem → Solution → Impact**
   - IoT-based Flood Early Warning System
   - MurgiBondhu — Poultry Temperature Monitoring
5. **Learning Journey** — Now / Next / Future + daily habits
6. **Contact** — Clean CTA + socials

## 🚀 Run Locally

```bash
cd portfolio
npm install
npm run dev
# open http://localhost:3000
```

## ✏️ Customize

All your content lives in **`lib/data.ts`**:

- `profile` — name, title, bio, email, location, socials
- `principles` — your 3 guiding values
- `skills` — grouped skill chips
- `projects` — each with problem/solution/impact
- `journey` — Now/Next/Future phases
- `habits` — your daily operating system

## 🌐 Deploy

Push to GitHub → import on [vercel.com](https://vercel.com) → Deploy. Done.
